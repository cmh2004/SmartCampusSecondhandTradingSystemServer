# 智能校园二手交易系统

随着人们生活水平的快速提高，对于作为年轻消费群体主力的高校学生来说，其日常学习和生活用品呈现了更换周期大大缩短的趋势。为了有效促进这些更换商品的循环再利用，同时也为了节省学习和生活成本，二手商品交易在校园中悄然兴起。然而在现有交易过程中，存在着因商品属性复杂导致价值评估难、商品寻找不便、风险提醒不足等问题。为此，本课题拟基于Qt框架，并借助大模型辅助，设计并实现一套包括校园常见二手商品自动识别与估价、商品发布、智能检索与推荐、议价与风险提醒、交易评价等功能的校园二手商品交易系统，旨在使二手商品交易过程更加公平、公正、公开，从而有效确保交易双方的合法权益。



本系统面向普通用户和管理员两类角色。普通用户可完成账号注册登录、资料修改、商品发布、AI估价、商品浏览与筛选、聊天、订单管理、收藏商品、查看浏览历史、查看信用分及变动记录、提交举报和售后纠纷、接收系统消息。管理员可进行商品审核、用户管理、纠纷处理、举报处理。建立完整的信用分奖惩机制，根据不同行为动态调整用户信用分，信用低的账号将被采取限制。

采用三层C/S架构。客户端层（表示层）基于Qt构建跨平台交互界面；服务端层包含业务逻辑层（处理API请求、AI调用、信用规则等）与数据访问层（封装MySQL增删改查操作）；数据存储层采用MySQL 8.0实现持久化。



本系统共设计14张数据表：用户表(user)、商品表(goods)、商品图片表(goods\_image)、分类表(category)、订单表(order)、聊天表(chat)、收藏表(favorite)、评价表(evaluation)、纠纷表(dispute)、举报表(report)、信用记录表(credit\_record)、系统消息表、AI估价记录表、浏览历史表。
